# Bundled demo

Run `npm run demo` from the repository root, then open <http://127.0.0.1:4173/examples/>.

The page uses the hosted Zaomeng Web Component runtime and the VRM files committed to this repository. The manifests deliberately point to GitHub raw asset URLs so the same demo works from localhost or a static host. The assistant menu keeps gaze-follow at the top, groups the five calibrated actions and six expressions, and lets you drag the avatar itself without a separate handle.

The two models are third-party assets. Read [`../THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md) before copying, modifying, deploying, or redistributing them.
