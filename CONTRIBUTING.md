# Contributing

Issues and pull requests are welcome.

Before submitting a change:

1. Keep `SKILL.md` concise and move framework-specific detail to `references/`.
2. Never add a model without documented authorship, source, embedded permissions, and SHA-256.
3. Run `npm test`.
4. Run `npm run demo`, open <http://127.0.0.1:4173/examples/>, and test desktop plus 390px.
5. Update `CHANGELOG.md` when behavior or installation instructions change.

Security-sensitive fixes should avoid publishing private Manifest URLs, tokens, model credentials, or personal data in an issue.
